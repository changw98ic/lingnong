# 《灵农修仙》游戏策划案 v0.2（已确认基线）

## 1. 项目概述

**暂定名**：灵农修仙（副标题：灵田问道）  
**类型**：国风 2D 单机增量经营 / 修仙种田  
**平台**：Steam（Windows 首发，开发阶段同步兼顾 Steam Deck）  
**引擎**：Godot 4.x  
**商业模式**：买断制，无强制联网、无内购  
**目标体验**：玩家用几分钟完成一轮经营，用几小时完成一次境界成长，用数十小时完成飞升。

## 2. 一句话卖点

种植灵植、炼制丹药、驯养灵兽，把一亩仙田经营成洞天福地，靠自己的农道一路飞升成仙。

## 3. 目标用户

- 喜欢《Melvor Idle》《NGU Idle》等增量成长的玩家
- 喜欢种田、生产链、收集和轻度经营的玩家
- 喜欢国风修仙题材，但不想进行高强度战斗的玩家
- Steam Deck 与键鼠休闲玩家

## 4. 核心循环

### 短循环（30 秒～5 分钟）

查看灵田 → 种植/收获 → 领取灵石、灵气、修为 → 购买即时升级。

### 中循环（10 分钟～2 小时）

解锁新灵植 → 配置灵田 → 炼丹加工 → 完成仙门订单 → 突破小境界。

### 长循环（数小时～数十小时）

解锁区域与灵兽 → 形成流派 → 完成大境界突破 → 飞升/转生 → 获得永久加成。

## 5. 资源体系

| 资源 | 用途 | 主要来源 |
|---|---|---|
| 灵石 | 设施、种子、灵兽升级 | 收获、订单、出售丹药 |
| 灵气 | 灵植培育、部分功法 | 灵田、聚灵阵、离线收益 |
| 修为 | 境界突破 | 收获、丹药、事件 |
| 灵材 | 炼丹与订单 | 灵植收获、秘境 |
| 仙缘 | 飞升后的永久成长 | 飞升、成就、特殊事件 |

## 6. 灵田与生产

### 首发目标

- 3 块灵田
- 20 种灵植
- 4 个品质层级：凡品、灵品、玄品、仙品
- 每块灵田可配置生长速度、产量、品质等方向

### 初始灵植示例

| 灵植 | 成长时间 | 产出 | 设计意图 |
|---|---:|---|---|
| 聚灵草 | 5 秒 | 灵石、灵气 | 教学与快速反馈 |
| 凝神花 | 30 秒 | 修为灵材 | 中期修炼路线 |
| 赤阳果 | 2 分钟 | 炼体灵材 | 高价值长周期 |
| 九转仙稻 | 15 分钟 | 大量灵石 | 中后期储蓄目标 |
| 天道莲 | 2 小时 | 突破材料 | 稀有目标与期待 |

## 7. 炼丹系统

玩家将灵材组合成丹药，丹药提供即时收益或临时增益。

- 聚气丹：立即获得灵气
- 筑基丹：获得修为并消耗稀有灵材
- 长生丹：一段时间内生长速度提升
- 聚财丹：一段时间内收获灵石提升

首发版本先采用配方解锁和一键炼制，不做操作型小游戏，避免破坏增量节奏。

## 8. 功法流派

玩家在关键境界选择主修功法，形成长期差异。首发计划 3 条流派：

- **青木道**：生长速度、产量、灵田效率
- **丹鼎道**：炼丹暴击、订单收益、配方解锁
- **御兽道**：自动化、离线收益、灵兽能力

原则：流派之间是不同经营风格，不设计绝对最优答案；允许后期付出代价切换。

## 9. 灵兽与自动化

- 灵鹤：自动播种
- 木灵童子：自动收获
- 金甲牛：增加灵田容量与产量
- 寻宝狐：提高稀有灵材概率
- 云游鹿：提高离线收益上限

自动化应逐步解放重复操作，但保留玩家做配置和路线选择的价值。

## 10. 境界与阶段目标

凡人 → 炼气 → 筑基 → 金丹 → 元婴 → 化神 → 炼虚 → 合体 → 大乘 → 渡劫。

示例解锁：

- 炼气：第二块灵田、基础离线收益
- 筑基：炼丹房与凝神花
- 金丹：灵兽系统与自动收获
- 元婴：秘境与第二个区域
- 化神：功法重修与高级订单
- 渡劫：飞升/转生终局

## 11. 离线收益与反异常

- 默认离线收益上限 8 小时
- 根据最后保存时间结算
- 检测到时间倒退时暂停离线收益并提示玩家
- 结算资源设置软上限，避免一次离线跳过大量内容
- 每 30 秒自动保存，关键行为即时保存

单机游戏不追求完全反作弊，优先保证存档安全与正常体验。

## 12. 主动内容

为了避免玩家只等待数字增长，加入低频、可选的主动内容：

- 每日灵田奇遇
- 五行天气
- 仙门订单
- 短时秘境采集
- 灵兽委托
- 限时稀有灵植

主动内容不应要求玩家持续高频点击。

## 17. 已确认设计决策

以下内容作为当前版本的正式设计基线：

1. **核心方向**：以挂机增量为基础，同时加入低频、可处理的主动事件。
2. **商业模式**：Steam 买断制，无内购、无广告、无强制联网。
3. **战斗系统**：不加入战斗。法术用于灵田管理、灾害处理和生产增益。
4. **终局结构**：飞升是当前一世的终局；寿元耗尽后到达大限，结算本世并开启转世。
5. **转世系统**：根据本世进度结算知识点，用知识点购买跨世永久强化。
6. **美术方向**：像素风国风。
7. **平台策略**：Windows 与 Steam Deck 兼顾，开发早期遵守手柄操作和 1280×720 可读性原则。
8. **Demo 时长**：目标约 2 小时，展示完整的种植、灾害、法术、境界成长和转世预告。

## 18. 灵田灾害与法术

主动事件是挂机循环中的低频打断。事件不要求玩家持续盯屏，但需要玩家在合适时机处理。

### 噬金虫

噬金虫会攻击正在生长的灵植。每次攻击先检查守护灵阵的剩余抵抗次数：

1. 如果守护灵阵还有抵抗次数，则消耗 1 次抵抗，不造成作物损失。
2. 如果守护灵阵的抵抗次数已经耗尽，则对该灵田施加虫害层数。
3. 虫害层数会降低生长速度和最终产量。
4. 虫害达到严重等级时，本轮灵草可能没有产量。
5. 噬金虫不会直接摧毁玩家的永久升级、知识点或已解锁内容。

### 庚金剑诀：驱虫法术

庚金剑诀是**专门驱逐噬金虫**的法术，与灵雨诀完全分离：

- 目标：驱逐当前灵田的噬金虫
- 效果：立即结束该灵田的虫害事件，并清除或降低虫害层数
- 消耗：20 点灵气
- 冷却：120 秒
- 不提供生长加速
- 需要在玩家达到对应修为后解锁

### 灵雨诀：生长法术

灵雨诀是**单独的生产增益法术**，不负责驱虫：

- 目标：选定一块灵田或覆盖全部已解锁灵田
- 效果：持续一段时间提高灵草生长速度
- 不会驱逐噬金虫
- 噬金虫存在时仍可施放，但只能加速剩余生长进度，不能消除虫害
- 可升级持续时间、加速倍率和覆盖范围

### 守护灵阵：防御设施

守护灵阵是可升级的灵田设施，用于抵抗噬金虫的前几次攻击：

- 每块灵田拥有独立的守护灵阵等级和抵抗次数
- 噬金虫每次攻击消耗 1 次抵抗次数
- 抵抗成功时不产生虫害层数
- 抵抗次数耗尽后，后续攻击才会造成减产
- 升级灵阵可增加最大抵抗次数，并缩短恢复时间或提高基础防护
- 庚金剑诀可以驱虫，但不会替代灵阵的长期防护价值

推荐的 Demo 初始参数：

| 参数 | 初始值 |
|---|---:|
| 噬金虫基础出现间隔 | 8～15 分钟 |
| 噬金虫攻击间隔 | 60～90 秒 |
| 守护灵阵初始抵抗次数 | 3 次 |
| 虫害最大层数 | 3 层 |
| 每层最大减产 | 25% |
| 灵雨诀持续时间 | 60 秒 |
| 灵雨诀生长速度加成 | +50% |
| 庚金剑诀冷却 | 120 秒 |

### 设计原则

- 首次噬金虫事件必须有明确教学，不应突然惩罚玩家。
- 守护灵阵优先承担容错，玩家有时间决定使用庚金剑诀还是升级设施。
- 放任事件不能毁掉数小时成果，绝收只针对当前一轮作物产量。
- 灵雨诀和庚金剑诀必须在 UI、图标、颜色和说明上明确区分。
- 灵兽可以在后期自动处理基础虫害，但不能让手动法术完全失去价值。

## 19. 寿元、大限与转世

### 寿元

寿元是本世的软时间限制。玩家可以通过长生类灵植、丹药和永久强化延长寿元。寿元归零时触发大限结算，并非突然删除存档。

### 飞升

飞升是当前一世的主要终局目标，需要达到渡劫境界并完成飞升准备。结算内容包括最高境界、灵田总产出、图鉴进度、灾害处理效率、剩余寿元和特殊成就。

### 转世与知识点

玩家在飞升后，或寿元大限到达后转世：

- 当前世的灵石、临时增益和大部分设施重置
- 图鉴、成就和知识点保留
- 根据当前进度获得知识点
- 使用知识点购买永久强化
- 开启新的起始优势和更高成长目标

知识点强化方向：初始资源、基础生长速度、灵田数量、离线收益上限、噬金虫出现间隔、灵雨诀效果、庚金剑诀冷却、守护灵阵初始抵抗次数和初始寿元。

## 21. 已确认的 Demo 交互方案

为避免后续反复讨论，本阶段采用以下实现基线：

- 灵雨诀：选择目标灵田，消耗 10 灵气，持续 60 秒，生长速度 +50%；不驱虫。
- 庚金剑诀：选择出现噬金虫的灵田，消耗 20 灵气，冷却 120 秒；驱虫后获得虫尸。
- 守护灵阵：每块灵田独立拥有等级与抵抗次数；初始抵抗 3 次，升级消耗 100 灵石并增加抵抗次数。
- 噬金虫：首次攻击在种植 180 秒后出现，之后每 60 秒攻击；抵抗次数耗尽后每次攻击增加虫害层数，最高 3 层，每层减产 25%。
- 祥瑞降世：限时 60 秒，收获产量翻倍。
- 兵主诞辰：限时 60 秒，噬金虫攻击数量翻倍。
- 虫尸：每具售价 8 灵石。
- 四季：每 180 秒轮换一次；春季生长速度 +25%，夏季灵气产出 +25%，秋季收获产量 +25%，冬季暂不提供额外加成。

## 22. 修士升级系统

修士成长分为四个层级，确保每种资源职责清晰：

```text
收获/炼丹获得修为 → 境界突破 → 解锁系统
灵石 → 灵田与设施升级
灵气 → 法术施放
知识点 → 转世后的永久强化
```

### 22.1 境界突破

境界是当前一世的主要成长阶段。Demo 开放：

| 境界 | 修为要求 | 主要解锁 |
|---|---:|---|
| 凡人 | 0 | 第一块灵田、聚灵草 |
| 炼气 | 100 | 第二块灵田、灵雨诀、基础离线收益 |
| 筑基 | 1,000 | 第三块灵田、庚金剑诀、守护灵阵 |

正式版继续开放金丹、元婴、化神、炼虚、合体、大乘、渡劫。每次突破必须带来新玩法或新目标，而不只是倍率提升。

### 22.2 修士专精

转世获得的知识点用于购买跨世永久专精。专精采用升级列表实现，后续可扩展为树状结构：

| 专精 | 每级效果 | 首级成本 |
|---|---|---:|
| 木灵根 | 生长速度 +5% | 20 知识点 |
| 聚气效率 | 灵气产出 +8% | 20 知识点 |
| 农道悟性 | 收获修为 +10% | 20 知识点 |
| 长生印记 | 本世寿元 +10 天 | 30 知识点 |

升级成本公式：

```text
当前成本 = 基础成本 × (1 + 已有等级 × 0.5)
```

这样玩家可以在转世后选择不同发展方向：

- **木灵路线**：更快的灵植循环
- **聚气路线**：更频繁地使用灵雨诀与庚金剑诀
- **农道路线**：更快推进境界
- **长生路线**：延长一世经营时间

### 22.3 本轮实现状态

当前 Godot 原型已接入：

- 境界与修为显示
- 灵石、灵气、修为、知识点、寿元显示
- 木灵根、聚气效率、农道悟性、长生印记按钮
- 转世后保留知识点与专精等级
- 四季轮换与资源 Buff
- 祥瑞降世与兵主诞辰
- 噬金虫攻击、守护灵阵抵抗次数、虫害减产
- 灵雨诀、庚金剑诀与虫尸售卖

## 23. 本轮落地验收标准

### 必须可运行

- 启动主场景不报脚本错误
- 点击空闲灵田可以种植聚灵草
- 作物成熟后可以收获灵石、灵气和修为
- 修为达到要求后可以突破并解锁灵田
- 灵雨诀不清除噬金虫，只加速生长

- 四季与随机事件能够影响收益或攻击频率
- 存档包含新增状态

## 24. 本轮已确认事项

以下内容不再作为待审阅项，直接作为实现基线：

- 灵雨诀只负责加速灵植生长，不驱虫。
- 庚金剑诀只负责驱逐噬金虫，驱虫后获得虫尸。
- 守护灵阵可升级，并抵抗噬金虫前几次攻击。
- 春季提升生长速度，夏季提升灵气产出，秋季提升产量，冬季暂不提供额外加成。
- 祥瑞降世期间产量翻倍。
- 兵主诞辰期间噬金虫攻击数量翻倍。
- 虫尸可出售换取灵石。
- 修士通过境界、设施、法术和转世知识点四层成长。

- 灵雨诀不驱虫，只加速生长。
- 庚金剑诀不加速，只驱逐噬金虫并产生虫尸。
- 守护灵阵通过升级提供前几次攻击的容错。
- 四季与祥瑞/兵主事件改变生产和灾害节奏。
- 修士通过境界、设施、法术和转世知识点成长。
