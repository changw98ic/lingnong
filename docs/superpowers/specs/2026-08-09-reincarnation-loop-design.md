# 轮回核心循环重构设计（2026-08-09）

## 设计原则

增量游戏不靠"强制惩罚玩家"，而是靠"生命周期压力迫使玩家选择重置"。寿元是决策而非倒计时；轮回是游戏心脏而非重置按钮。

## 第 1 节：寿元与轮回（已确认）

- 寿元衰减 0.5 → 0.2 年/秒（5 秒 = 1 年）；寿元表 [60,120,200,500,2000] → [80,120,300,1000,3000]。
- 随时轮回按钮（修炼·突破面板）：奖励 = 保留未用天赋点 + 本世新跨里程碑 ×2 + 本世突破 ×1；提前轮回（寿元 >20%）×80%，天人五衰立即轮回 ×100%。
- 天人五衰（寿元 <20% 三选择）：
  - 立即轮回：100% 奖励。
  - 继续修炼：生产 -50% 至寿元耗尽，每 60 秒 roll 天命奇遇（奇遇池）。
  - 渡劫续命：消耗 3 种渡劫丹各 1 + 当前境界寿元上限 20% 的灵石；成功寿元 +50 年并解除衰败；失败寿元归零、强制轮回且奖励 ×80%。
- 存档 v18：本世起始里程碑/晋级数、衰败状态、奇遇计时、渡劫续命状态。

## 第 2 节：突破失败机制 + 雷劫重构（已确认）

- 突破前成功率选择：稳定（材料 ×1.5，95% 成功率）/ 强行（材料 ×1，50%）；失败得碎丹经验（下次 +15%，封顶 +45%），不损失修为。
- 雷劫改为生产体系检测 3 道检查：
  - 第一劫·灵气：当前灵气 ≥ 10,000（治疗丹使需求减半）。
  - 第二劫·底蕴：本世累计收获 ≥ 1,000（抗性丹使需求减半）。
  - 第三劫·气运：本世触发过随机事件 ≥1 或幸运达标（强化丹直接通过）。
- 失败获得永久"雷劫淬体"：生产/修为 +5%（每次失败累计，跨局保留）。
- 渡劫丹改"渡劫准备"用途：不再点击回血。

## 第 3 节：宝箱奇遇 + 转世三选一 + 事件池（已确认）

- 收获时 roll：木箱 5%（灵石/灵气）、玉箱 1%（材料/悟道残卷/聚气玉）、仙箱 0.1%（永久强化：生产 +2%、寿元上限 +20 年、暴击率 +1%，跨局保留）、古修遗物 1%（玉/仙箱池随机）。
- 新 `TreasureSystem` 系统类，掉落表进 `BalanceConfig`。
- 转世天赋三选一（轮回后本世生效、跨世不保留）：青木神通（产量 +50%）、丹心（修为 +20%）、天命（奇遇概率 ×5）。
- 事件池扩展：古修洞府（三选一：灵石/天赋点/随机宝箱）、天降灵种（解锁高级灵植）、魔气侵染（生产 -50%，灵石净化）、噬金虫王（boss 虫害，剑诀击杀得虫尸 ×10）。

## 实施顺序

1. balance_config 数值表 → 2. game_state 轮回/衰败/突破/雷劫/宝箱/事件 → 3. treasure.gd → 4. simulation 倍率 → 5. save_manager v18 → 6. 探针 → 7. 面板 → 8. 文档。
