# 成就化平衡重构设计记录（2026-08-08）

## 背景

针对 Steam 增量游戏差距分析后，围绕「天赋点 = 多成就来源」重构长期成长：寿元衰减过紧导致零天赋玩家无法完成凡人→炼气循环、天赋点来源单一（突破+里程碑+商店）、离线结算与时长挂钩却只结算自动修炼、炼丹退出主循环后留下空壳。

## 确认的设计决策

### 1. 寿元衰减

- `LIFESPAN_DECAY_PER_SECOND: 2.0 → 0.5` 年/秒。
- 依据：探针实测零天赋凡人→炼气需 84 秒，而 2.0 衰减下凡人仅 30 秒寿命，必然卡死。0.5 后凡人 120 秒、炼气 240 秒、筑基 400 秒、金丹 1000 秒，循环成立且保留压力。

### 2. 突破天赋点

- 替换原 `1 + 境界序号`（炼气 2 / 筑基 3 / 金丹 4）为按境界索引表 `[0, 3, 7, 15]`（凡人 0 / 炼气 3 / 筑基 7 / 金丹 15），随突破发放并累计晋级次数。

### 3. 种植熟练度（跨大限、跨新局永久）

- 共享门槛 `[10, 50, 150, 400]`，奖励按灵植定义（每种作物独立累计收获次数）。
- 产量奖励取当前最高档位（1/1/2/3），成熟时间减免取已达档位最大值，天赋点按首次跨门槛逐档累计（1+2+3+5=11 点/作物，共 44 点）。
- 奖励表：聚灵草 -1 秒、凝神花 -2 秒、赤阳果 -5 秒、天道莲 -60 秒。
- 接入点：`harvest_crop` 计数发点；`SimulationSystem.field_result` 应用产量加成；`crop_base_growth_seconds` / `live_crop_growth_seconds` 应用时间减免。

### 4. 成就系统（方案 C：独立类）

- 新建 `AchievementSystem`（静态查询 + 一次性解锁），19 项成就定义在 `BalanceConfig.ACHIEVEMENTS`，共 49 成就点。
- 成就点独立于修为、灵石、天赋点主经济；解锁检查挂在 `GameState.emit_state_changed()` 统一出口，不重复发点；加载时点数按当前定义重算。
- 指标：总收获次数、累计修为、境界、灵田数、单作物熟练度、轮回次数、天赋节点数。

### 5. 离线一次性折算（完全替换离线自动修炼）

- 与离线时长无关，只按长期计数发放尚未领取的差额，防反复开关游戏刷奖。
- 天赋点 = `min(轮回次数,3) + min(floor(晋级次数/2),2) + min(floor(总收获次数/2000),2)`，总上限 7。
- 灵石 = `(轮回次数×50 + 晋级次数×100 + 总收获次数×2) × 当前境界生产倍率`。
- 离线不增加修为和灵气；大限未续命时不发放（预览显示待领差额）；领取账本持久化。

### 6. 炼丹移除 + 狂暴丹进商店

- 炼丹整体删除：`AlchemySystem`、炼丹标签页、`brew_pill`/`consume_pill`、`pills` 存档字段、6 个旧解锁标志、`RECIPES`/品质常量、炼丹模拟矩阵全部移除；天赋树丹道分支保留（已是灵田修为倍率）。
- 狂暴丹（商店商品）：生产 ×3、持续 5 秒，基础价 100 灵石，每次购买后 ×1.5 递进（四舍五入到 10，不设上限）；购买次数跨大限保留、新游戏重置；大限期间不可购买；连买顺延持续时间；HUD 狂暴标签复用。

### 7. 存档升级

- v10 → v11（熟练度/成就/计数/领取账本）→ v12（成就按定义校正）→ v13（删 pills 与旧解锁标志，加 `shop_purchase_counts`）。
- 旧档迁移：晋级计数缺失时按当前境界补基线；成就只接受当前定义 id 并重算点数。

## 落地状态

- 设计讨论期间用户侧已实现 1–5、7（探针 60+ 检查覆盖）；本次会话实现 6（狂暴丹 + 炼丹清理）并同步探针。
- 验证：`field_balance_probe` 全绿（含狂暴丹递进价格 100/150/230/340、大限拦截、跨局保留）；`--editor --quit` 与主场景 headless 无错误。
- 文档基线：README、CLAUDE.md、CURRENT-GAME-FLOW.md 已同步。

# 2026-08-09 扩展：元婴层级 + 天赋树加深/幸运系 + 成就扩展

## 确认的设计

### 元婴（终点层，第 5 境界）

- 门槛 1 亿修为（金丹 200 万的 ×50）、生产/修炼 ×100、寿元 2,000 年（0.5 衰减 ≈ 66 分钟一轮）、突破天赋点 +31（表 `[0,3,7,15,31]`）。
- 突破材料 7 种各 1 份（紫府玉髓、元婴道果、雷劫淬体、天劫雷晶、太虚一气、九转还魂草、天机符石），单价 200 万灵石（总成本 1,400 万 ≈ 元婴阶段 1 分钟收入标定）。
- 新作物紫芝（900 秒 / 修为基值 2,000 / 单价 5,000，元婴解锁，熟练度减免 30 秒档），熟练度共 5 作物 55 点。
- 灵田体系不动（仙田 ×1000 已是最高档）；元婴期档位回本快于旧标定区间（33 秒 vs 45~90 秒），探针断言跳过元婴层。

### 天赋树扩展（+7 节点，总费用 30 → 55）

- 三系加深（cost 5，前置各系顶点）：丰收大道（生产 ×2.0）、问道丹心（修为 ×2.0）、紫府开辟（自动修炼 ×2.0）。
- 第四系·幸运系（cost 1+2+2+5=10，前置根节点）：
  - 幸运入门：暴击率 +5%；天降横财：10% 概率额外灵石 ×50%；福星高照：稀有暴击 +20%（×5 替代 ×2）；天道眷顾：暴击率 +10%、稀有 +15%。
- 新机制：`TalentTree.bonus()`（相加语义）支持概率类效果；收获时在 `harvest_crop` roll 暴击/稀有/横财；模拟器 `field_result` 展示期望倍率（修为与灵石分开）。
- 新长期统计：crit_count / rare_crit_count / windfall_count（存档 v17，成就用）。

### 成就扩展（19 → 36 项）

- 灵田：收获 5,000/10,000 次、3 田全仙田（新 metric `all_fields_max_tier`）。
- 修行/境界：修为 1 亿/10 亿、达到元婴。
- 熟练度：凝神花/赤阳果 400 宗师、四作物 1,000 大宗师、紫芝 10 入门。
- 幸运：暴击 10/500 次、稀有暴击 50 次、横财 50 次。
- 轮回/天赋/商店：新局 10 次、天赋 10 节点、狂暴丹 10 次（新 metric `shop_purchase_count`）。

## 实施要点

- 探针适配：元婴层档位回本断言跳过（境界倍率 ×100 使回本快于标定期）；全量矩阵档位数用 `mini(realm+1, FIELD_TIER_MULTS.size())`；突破点/熟练度/晋级计数断言更新；最大化模拟点数断言改为账目平衡关系；暴击采样区间按期望 1.4575 标定（1.3~1.7）。
- 验证：探针全绿（含"开始元婴天劫 / 天劫成功后进入元婴"完整流程）、主场景 headless 无错误、突破节奏（满天赋 4 次/秒全程约 646 秒，零天赋约 8.5 小时）。
