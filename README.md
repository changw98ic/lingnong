# 灵农修仙

一款国风修仙题材的单机增量游戏原型。核心不是反复点击，而是把灵田、修为、灵石、自动化和天赋树叠成越来越快的生产循环。

基于 Godot 4.7.1，使用 GDScript。

## 核心循环

```text
种植灵植
  → 自动收获并补种，点击生长中的灵田加速；生长中可切换作物并重新计时
  → 收获直接获得修为和灵石，不获得灵气
  → 修为达到门槛并在商店备齐突破材料后开始天劫
  → 使用治疗丹、抗性丹、强化丹渡过天劫，成功后才提高生产与修炼倍率
  → 修为里程碑和突破获得天赋点
  → 在天赋树选择下一条增量路线
  → 完成成就，记录灵田、修行、熟练度和轮回目标
  → 商店购买狂暴丹（越买越贵）换取短时生产爆发
```

没有单独的转世按钮；寿元进入大限后，玩家可以开始新局。熟练度、晋级次数、轮回次数、收获统计和成就属于跨大限的长期进度，天赋树、境界、灵田升档、修为里程碑和成就点共同承担成长。

## 灵气的用途

灵气不再由灵田收获产生，当前来源是自动修炼和商店补给。它有两个用途：

1. **增强收获**：每 100 点当前灵气使收获增加 10%，基础收获加成最多 ×3；灵根天赋可以继续放大这段加成。
2. **施放法术**：灵雨诀消耗 10 灵气，庚金剑诀消耗 20 灵气。

灵气不会因为收获加成自动消耗，因此玩家要在“保留高灵气提高收获”和“施法处理灵田”之间做选择。

## 点击加速

- 作物默认**自动收获并自动补种**，适合放置运行。
- 点击生长中的灵田会减少成熟倒计时，基础每次减少 1 秒。
- 农道天赋可以进一步提高每次点击的加速时间。
- 作物成熟后自动结算，玩家不需要在成熟时手动结算。

## 寿元

寿元按运行时间流逝，当前基础速度为每秒 0.5 年，不再按种植次数扣除。

- 凡人 / 炼气 / 筑基 / 金丹 / 元婴的寿元上限分别为 60 / 120 / 200 / 500 / 2,000 年。
- 对应一轮默认真实时长约为 2 分钟 / 4 分钟 / 6.7 分钟 / 16.7 分钟；长生印只在此基础速度上继续降低流逝。
- 突破会提高上限并补满寿元。
- 寿元归零进入“大限”：自动种植、收获和自动修炼暂停，不删除本轮进度。
- 商店中的长生丹可以恢复寿元；也可以在“修炼·突破”面板手动结束本轮并开始新局。
- 开始新局时轮回次数 +1，保留天赋树、未用天赋点、修为里程碑、灵植熟练度、成就、商店购买次数和长期统计，清空本轮资源与境界。

## 境界与倍率

| 境界 | 生产倍率 | 修炼倍率 | 累计修为门槛 |
|------|---------:|---------:|-------------:|
| 凡人 | ×1 | ×1 | 0 |
| 炼气 | ×3 | ×3 | 1,000 |
| 筑基 | ×8 | ×8 | 80,000 |
| 金丹 | ×20 | ×20 | 2,000,000 |
| 元婴 | ×100 | ×100 | 100,000,000 |

突破材料不属于可种植作物，只能在商店兑换：炼气需要服气丹×10；筑基需要金阳花、紫木根、碧水莲、炎灵树心、大地苦草各 1；金丹需要雷击桃木、福禄咒、三清敕令、阳极地心、阴极月华、苍天紫气各 1；元婴需要紫府玉髓、元婴道果、雷劫淬体、天劫雷晶、太虚一气、九转还魂草、天机符石各 1（单价 200 万灵石）。材料在开始天劫时消耗，渡劫失败后需要重新购买。

### 天劫

突破按钮不会直接改境界，而是进入暂停生产的渡劫阶段。初始为九九天劫（99 道），未用天赋点达到 10 点时降为六九天劫（69 道），达到 25 点时降为三九天劫（39 道）；天赋点只检查当前未使用的点数。

- 劫体初始 100 点，每道雷劫基础造成 2 点伤害。
- 治疗丹：1,500 灵石，渡劫中恢复 30 点劫体。
- 抗性丹：2,000 灵石，获得 10 道抗性，期间雷劫伤害减半。
- 强化丹：2,500 灵石，本次渡劫劫体上限 +50、雷劫伤害 ×0.8，每次渡劫限用 1 枚。
- 玩家可以手动迎接下一道，也可以等待每秒自动结算；渡劫期间暂停种植、收获、事件和自动修炼。
- 劫体归零即渡劫失败，境界不变；全部劫数结算成功后才发放突破天赋点、寿元和境界解锁。

灵田槽位和灵田档位都用灵石购买：

- 第 1 块灵田免费；第 2 块和第 3 块的凡人基准价分别为 100、500 灵石，实际价格随当前境界生产倍率缩放：炼气为 300、1,500，筑基为 800、4,000，金丹为 2,000、10,000；不设境界购买门槛。
- 灵田档位为凡田 / 灵田 / 宝田 / 仙田，对应 ×1 / ×10 / ×100 / ×1000 的单次产出倍率。
- 炼气、筑基、金丹分别开放购买灵田升至灵田、宝田、仙田；对应费用为 4,000 / 120,000 / 3,000,000 灵石。费用按农道核心天赋下约 1 分钟回本标定，未点农道时约 2.5~3 分钟；灵气、事件、狂暴丹和点击属于额外爆发。

## 天赋树

天赋点来源：

- 每次境界突破按境界索引获得 `[0, 3, 7, 15, 31]` 点（凡人、炼气、筑基、金丹、元婴）。
- 五种灵植分别在累计收获 10 / 50 / 150 / 400 次时获得熟练度奖励；每种灵植贡献 1+2+3+5 = 11 点，五种共 55 点。
- 累计修为达到 1 千、1 万、10 万、100 万等里程碑时获得天赋点。
- 商店可以用灵石购买悟道残卷。

熟练度的产量与成熟时间奖励按当前最高档位生效，天赋点按首次跨过门槛累计：

| 作物 | 10 次 | 50 次 | 150 次 | 400 次 |
|---|---|---|---|---|
| 聚灵草 | 产量 +1 | 产量 +1、成熟 -1 秒 | 产量 +2 | 产量 +3、成熟 -1 秒 |
| 凝神花 | 产量 +1 | 产量 +1、成熟 -2 秒 | 产量 +2 | 产量 +3、成熟 -2 秒 |
| 赤阳果 | 产量 +1 | 产量 +1、成熟 -5 秒 | 产量 +2 | 产量 +3、成熟 -5 秒 |
| 天道莲 | 产量 +1 | 产量 +1、成熟 -60 秒 | 产量 +2 | 产量 +3、成熟 -60 秒 |

天赋树是节点图，不是固定等级条。每条路线的第二层都有两个方向，分支终点只需完成其中一个方向；每系顶点之后还有元婴级加深节点（×2.0），第四系·幸运系提供收获暴击（普通 ×2 / 稀有 ×5）与天降横财：

- **农道**：生产倍率 / 生长速度 / 点击加速 / 丰收大道（产出 ×2.0）。
- **丹道**：灵田收获修为 / 修为倍率 / 问道丹心（修为 ×2.0）。
- **灵根**：灵气产出 / 自动修炼 / 寿元流逝 / 灵气收获加成 / 紫府开辟（自动修炼 ×2.0）。
- **幸运**：暴击率（最多 +15%）/ 稀有暴击（+35%）/ 天降横财（10% 概率额外灵石 ×50%）。

## 商店

商店面板提供七种可重复购买的资源转换：

| 商品 | 价格 | 效果 |
|------|-----:|------|
| 长生丹 | 1,000 灵石 | 恢复 30 年寿元 |
| 聚气玉 | 1,000 灵石 | 获得 200 灵气 |
| 治疗丹 | 1,500 灵石 | 渡劫中恢复 30 点劫体 |
| 抗性丹 | 2,000 灵石 | 渡劫中获得 10 道减半伤害的抗性 |
| 强化丹 | 2,500 灵石 | 本次渡劫劫体上限 +50、伤害 ×0.8，每次限用 1 枚 |
| 悟道残卷 | 500 灵石 | 获得 1 天赋点 |
| 狂暴丹 | 100 灵石起，每次购买后 ×1.5 递进（四舍五入到 10，不设上限） | 生产 ×3，持续 5 秒；连买可延长持续时间 |

狂暴丹的购买次数跨大限新局保留，新游戏重置。价格按累计购买次数计算，因此越买越贵，是灵石的长线消耗出口；配合“祥瑞降世”事件窗口使用效果最佳。大限期间不能购买狂暴丹。

突破材料也在商店单独兑换，按当前境界开放；不会出现在灵植列表，也不会由种植或其他生产线生成。

## 成就

成就是独立的长期目标，不与修为、灵石或天赋点主经济重复叠加。当前共 36 项，进入“成就”标签页查看：

- 灵田：累计收获 1 / 100 / 1,000 次，购买第 2 / 3 块灵田。
- 修行：累计获得 1,000 / 1,000,000 点修为，达到炼气 / 筑基 / 金丹。
- 熟练度：四种灵植分别达到 10 次入门；聚灵草和天道莲达到 400 次宗师。
- 轮回：开始第 1 / 3 次新局；天赋：解锁 5 个天赋节点。
- 成就解锁由 `GameState.state_changed` 统一触发，成就状态和成就点随存档、开始新局永久保留。

## 主要系统

- 四种灵植：聚灵草、凝神花、赤阳果、天道莲。
- 自动修炼：筑基解锁，按正在种植的灵田浓度结算。
- 商店：长生丹续命、聚气玉补灵气、治疗/抗性/强化丹渡劫、悟道残卷换天赋点、狂暴丹（越买越贵）换生产爆发。
- 四季、祥瑞降世、天道感悟、兵主诞辰。
- 噬金虫、灵雨诀、庚金剑诀、守护灵阵。
- 成就系统：自动记录收获、修行、境界、灵田、熟练度、轮回和天赋目标。
- 离线折算与离线时长无关：天赋点 = `min(轮回次数,3) + min(floor(晋级次数/2),2) + min(floor(总收获次数/2000),2)`，上限 7；灵石 = `(轮回次数×50 + 晋级次数×100 + 总收获次数×2) × 当前境界生产倍率`。离线不增加修为和灵气；大限未续命时不结算。
- 游戏内数值模拟：实时状态、全境界、作物、熟练度、四季、天赋、事件、突破流程和全量核心矩阵；结果直接读取 `GameState` 与唯一数值配置，不维护独立数值表。
- JSON 存档，当前存档版本 17；成就、成就点、熟练度、幸运计数、商店购买次数、累计获得天赋点、当前局突破材料库存、渡劫进度和渡劫丹库存都会保存。

## 游戏内数值模拟

打开“数值模拟”标签页，可以直接观察当前状态和参数变化后的结果：

- 实时状态：读取每块已购买灵田的作物、档位、虫害、灵雨和当前灵气。
- 境界 × 灵田：比较凡人、炼气、筑基、金丹以及 1/2/3 块田的总产能、槽位成本和回本时间。
- 作物、四季、天赋、事件和境界矩阵：逐项展示产量、直接修为、灵石、自动修炼和解锁内容。
- 熟练度矩阵：逐种灵植展示 0/10/50/150/400 次档位、产量加成、成熟时间减免和天赋点累计。
- 突破流程：输入点击频率、田数、档位和天赋路线，按“种植 → 收获直接修为和灵石 → 校验商店材料 → 开始天劫 → 校验渡劫丹 → 完成天劫”推进到目标境界；报告会分别列出修炼时间和天劫时间，材料和丹药校验默认开启，关闭任一项时结果明确标记为时间估算。
- 突破流程开启“自动加点并最大化购买”后，天赋点到账立即按当前突破修为收益解锁节点；灵石优先购买寿元、突破材料和渡劫丹，余量再购买能提高修为速率的聚气玉。该模式会记录每阶段的自动加点、灵石购买和剩余资源。
- 点击分配默认按玩家全局频率计算；需要比较“每块田各自 4 次/秒”时，可在面板切换为每块灵田独立模式。
- 全量核心矩阵：遍历内部配置中的境界、已解锁作物、四季、天赋路线、田数和可用档位。
- 模拟结果只读，不改变当前游戏；状态变化后会自动刷新，也可以导出到 `user://simulation_report.json`。

## 数值统一管理

所有可调玩法数值集中在 `scripts/systems/balance_config.gd` 的 `BalanceConfig`：境界、突破天赋点、天劫、渡劫丹、作物、熟练度、成就、四季、灵田价格与倍率、天赋、商店、事件、自动化、离线和法术参数都从这里读取。

`GameState` 保存状态，`AchievementSystem`、`RealmConfig`、`CropConfig`、`TalentTree`、`AutomationSystem` 和 `ShopSystem` 只提供规则查询；真实收获与游戏内模拟共同调用 `SimulationSystem`。修改平衡时直接改 `BalanceConfig`，再运行 headless 探针即可检查真实结算和模拟结果是否同步。
