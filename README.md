# 灵农修仙

Godot 4.x 2D 单机增量经营游戏原型。

## 当前状态

已建立并通过 Godot 4.7.1 无头模式加载验证的项目骨架：

- Godot 项目配置
- `GameState` 全局状态
- JSON 存档管理
- 3 块灵田原型
- 聚灵草收获进入库存，商店出售换取灵石
- 商店购买聚气丹，服用后获得修为并推动境界突破
- 第一次体验：一轮收获 → 出售 → 买丹药 → 服用即可达到炼气要求
- 修为与境界突破
- 四季 Buff：春季生长、夏季灵气、秋季产量
- 随机事件：祥瑞降世、兵主诞辰
- 噬金虫事件与攻击结算
- 灵雨诀：单独加速生长
- 庚金剑诀：专门驱逐噬金虫并获得虫尸
- 可升级守护灵阵：抵抗噬金虫的前几次攻击
- 虫尸出售换取灵石
- 30 秒自动保存
- 当前游戏策划案：`docs/GDD-v0.1.md`（v0.2 已确认基线）

## 当前原型操作

1. 点击空闲灵田种植聚灵草。
2. 等待约 5 秒后点击成熟灵田，将聚灵草收入库存。
3. 在右侧商店点击“出售 1 株”，获得 5 灵石。
4. 点击“购买 1 枚聚气丹”，再点击“服用 1 枚聚气丹”，获得 50 修为。
5. 点击“尝试突破”：50 修为可立即突破炼气并解锁第二块灵田。
6. 点击灵田选择目标，再使用灵雨诀、庚金剑诀或升级守护灵阵。
4. 噬金虫出现后，庚金剑诀可以驱逐并获得虫尸。
5. 点击“出售虫尸”将虫尸换成灵石。
6. 木灵根、聚气效率、农道悟性和长生印记使用转世知识点购买。
7. 点击“转世”结算本世进度并保留知识点与永久专精。
8. 使用“保存”按钮或等待自动保存。

## 策划案审阅状态

已根据当前决策更新 `docs/GDD-v0.1.md`：

- 挂机增量为基础，加入低频主动事件
- 灵雨诀只负责生长加速
- 庚金剑诀只负责驱虫
- 守护灵阵抵抗前几次攻击并可升级
- 四季 Buff、祥瑞降世、兵主诞辰
- 噬金虫尸体可出售
- 无战斗、买断制、像素风
- 飞升终局、寿元大限、转世和知识点
- Demo 目标约 2 小时

修士成长采用四层结构：

```text
收获资源 → 修为 → 境界突破
灵石 → 灵田与守护灵阵升级
灵气 → 灵雨诀与庚金剑诀
知识点 → 转世后的永久专精
```
