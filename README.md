# 灵农修仙

一款国风修仙题材的单机增量（放置）游戏。不是种田模拟——种田只是第一桶金的来源，真正的玩法是借境界突破把全局产能一档一档推上去，再用炼丹、灵气浓度、爆发窗把这些产能放大。

基于 Godot 4.7.1，GDScript 单机原型。

## 核心循环

```text
种聚灵草 → 收获入库存
        → 出售换灵石，或投进炼丹炉炼丹
        → 灵石买聚气丹 / 炼出的丹药服用得修为
        → 修为满了境界突破
        → 境界本身就是全局乘数，同时解锁更强的生产手段
```

每一次突破都不只是“开一个新按钮”，而是把生长、产量、灵气、自动修炼的整体档位拉高一截，让下一档玩法比上一档快上数倍。

## 境界即乘数

境界既是进度门槛，也是全局产能倍率。突破到新境界后，生产类结算乘 `production_mult`，丹药与自动修炼的修为部分乘 `cultivation_mult`：

| 境界 | production_mult | cultivation_mult | 累计修为门槛 |
|------|-----------------|------------------|--------------|
| 凡人 | 1.0             | 1.0              | 0            |
| 炼气 | 5.0             | 2.0              | 100          |
| 筑基 | 50.0            | 10.0             | 1500         |
| 金丹 | 500.0           | 100.0            | 30000        |

`production_mult` 作用于：生长速度、收获产量、灵气产出、自动修炼的灵气部分。
`cultivation_mult` 作用于：丹药修为、自动修炼的修为部分。

各境界同时解锁关键系统：

- **炼气**：第二块灵田、灵雨诀、自动收获。
- **筑基**：第三块灵田、炼丹炉（筑基丹 / 狂暴丹）、灵田升级、庚金剑诀、守护灵阵、自动修炼。
- **金丹**：金元丹配方、灵脉化田。

## 灵田系统

灵田不靠堆数量，而靠单块田成长。每块田带三个成长维度：等级、品质、是否灵脉化。

- **田自身产量乘数**：`品质 × (1 + (等级-1) × 0.2)`。
- **筑基解锁升级田**：消耗 `50 × 当前等级` 灵石，等级 +1，逐步抬升单块田产量。
- **金丹解锁灵脉化田**：消耗 500 灵石，品质 ×3.0 并标记为灵脉田；灵脉田同时大幅提升灵气浓度（见下）。

境界突破给的灵田数量：凡人 1 块、炼气 2 块、筑基 3 块（满）。之后产能提升靠升级和灵脉化，而不是继续开田。

## 炼丹

炼丹炉把灵草换成丹药。配方由炼丹系统统一管理，炼制时校验灵草数量与境界解锁：

| 丹药 | 配方（灵草） | 效果 | 解锁境界 |
|------|-------------|------|----------|
| 筑基丹 | 10 株 | 服用得 1000 修为 | 筑基 |
| 金元丹 | 100 株 | 服用得 30000 修为 | 金丹 |
| 狂暴丹 | 30 株 | 服用后 60 秒内全局生产 ×3（爆发窗） | 筑基 |

聚气丹（5 灵石购买、服用得 50 修为）仍走“花灵石购买”的旧流程，不占炼丹炉配方，用于开局过渡。

狂暴丹不直接给修为，而是开一个生产爆发窗，配合收获 / 炼丹 / 自动修炼一起吃满乘数。

## 灵气浓度与自动修炼

灵气浓度由“正在种植的田”贡献：每块普通田 +1，每块灵脉化田 +10。它驱动筑基以后的自动修炼：

- **自动修炼修为/秒** = `浓度 × 0.5 × cultivation_mult × 转世倍率`
- **自动修炼灵气/秒** = `浓度 × 0.2 × production_mult × 转世倍率 × 事件生产倍率`

每帧结算，自动累加进修为与灵气。**离线也涨**：加载存档时按上述速率补算离线时段，封顶 8 小时（28800 秒），自筑基起生效。多块灵脉化田可以把浓度堆得很高，是金丹期的主要被动来源。

## 法术

- **灵雨诀**（炼气解锁）：消耗 10 灵气，让目标田生长速度 ×8 持续 60 秒。只加速生长，不直接给修为、不驱虫。
- **庚金剑诀**（筑基解锁）：消耗 20 灵气，120 秒冷却，驱逐目标田上正在发作的噬金虫并获得虫尸；虫尸可出售换灵石。只处理虫害，不加速生长。
- **守护灵阵**（筑基解锁）：可升级，抵抗噬金虫的前几次攻击；消耗 100 灵石升级，增加免伤次数。与剑诀是两套互补机制——阵抗小虫，剑诀清大虫。

## 事件与四季

- **四季**（每 180 秒一季）：春季生长 ×1.25，夏季灵气 ×1.25，秋季产量 ×1.25，冬季正常。
- **祥瑞降世**（随机事件，60 秒）：全局生产倍率 ×5，作用于生长、产量、灵气、自动修炼灵气。是主要的爆发收益窗。
- **兵主诞辰**（随机事件，60 秒）：噬金虫攻击频率与次数翻倍，是主要的压力窗。
- 噬金虫会周期性攻击种植中的田，造成产量衰减；守护灵阵与庚金剑诀是应对手段。

所有生产类乘数（季节、事件、境界、转世、狂暴丹、木灵根等）集中在生长 / 收获 / 灵气 / 自动修炼的统一结算里，不在按钮逻辑里散落。

## 转世

修士成长用知识点跨世升级。转世时：

- **保留**：知识点、修士专精（木灵根 / 聚气效率 / 农道悟性 / 长生印记）、转世次数。
- **转世倍率**：`1 + 0.5 × 转世次数`，全局乘到所有产出上。第一世 1.0，第二世 1.5，第三世 2.0……
- **重置**：境界归零、灵田清空（等级 / 品质 / 灵脉化全部还原）、解锁标志清空、狂暴丹爆发窗清空，给 100 灵石启动资金。

知识点按本世成就结算（境界、修为、虫尸、寿元），用于购买永久专精：木灵根（生长 +5% / 级）、聚气效率（灵气 +8% / 级）、农道悟性（丹药修为 +10% / 级）、长生印记（寿元 +10 天 / 级）。因为转世倍率叠进全局产出，第二世会比第一世明显更快推进。

## 操作

鼠标驱动：

- 点击空闲灵田种植聚灵草；点击成熟灵田收获入库存。
- 右侧商店：出售聚灵草换灵石、购买聚气丹、服用各类丹药、炼制筑基丹 / 金元丹 / 狂暴丹。
- 选中灵田后使用灵雨诀、庚金剑诀、升级守护灵阵。
- 修为达标后点击“突破”进入下一境界，自动解锁对应系统。
- 修士专精用知识点购买（转世后生效）。
- 点击“转世”结算本世、保留永久进度。
- 每 30 秒自动保存，也可手动保存。

## 运行

需要 Godot 4.7.1（`/opt/homebrew/bin/godot` 或 `/Applications/Godot.app`）。

```bash
# 运行主场景
godot --path .

# 打开编辑器
godot --editor --path .

# 无头校验项目加载与脚本解析
godot --headless --path . --editor --quit
```

存档位于 `user://lingnong_save.json`，当前存档版本 7。
